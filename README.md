# 浩煜 · 万家灯火

HaoYu（浩煜）是一个面向需求发布、协作交付与资金托管的可信价值协作平台。它把任务大厅、接单协作、成果提交、验收结算、钱包流水、通知中心、信任治理和后台管理放在同一套产品体验里，让每一份需求都有清晰路径，让每一次协作都有记录与回响。

项目当前以“浩煜·万家灯火 / 暖金夜色 / 深色玻璃 / 城市灯火”为视觉基准，提供前台业务页面、管理端页面和 `/design-showcase` 高保真产品展示页。

## 项目定位

浩煜不是单纯的任务列表 Demo，而是一套围绕“发布需求 -> 资金托管 -> 接单协作 -> 成果提交 -> 验收结算 -> 信用沉淀”的闭环系统。

它适合承载这些场景：

- 设计创意、开发技术、文案策划、视频动画、营销推广等轻协作任务
- 有预算、有交付物、有验收节点的服务交易
- 需要平台托管资金、留痕通知、争议处理和后台治理的协作流程
- 面向 PC 端优先的任务大厅、工作台、钱包与管理端体验

## 核心能力

### 任务市场

- 公开任务大厅与任务详情页
- 任务分类、预算、服务方式、状态标签展示
- 需求发布、参考图上传、预算录入和资金托管提示
- 我的任务、我接的订单、任务详情协作链路
- 子任务、评论、成果提交、验收和争议入口

### 钱包与资金托管

- 可用余额、冻结金额、总资产展示
- 发布任务时的资金冻结与后续结算链路
- 钱包流水追踪，覆盖充值、冻结、解冻、任务收入、提现、平台调账等类型
- 前端强调“托管、安全、透明、可追溯”，后端保留真实资金状态机约束

### 通知中心

- 未读通知统计
- 任务状态、验收、结算、争议和系统通知
- 单条已读、全部已读与页面事件刷新
- 深色玻璃空状态和通知列表视觉

### 个人中心

- 头像、昵称、邮箱、角色、余额、简介、创建时间
- 预设头像与自定义头像 URL
- 修改密码入口
- 首页右侧个人工作台，展示余额、通知、账号状态和快捷入口

### 信任与争议治理

- 信任中心展示资金托管、过程留痕、信用沉淀和争议治理说明
- 争议处理能力由后端接口与后台入口支撑
- 管理端保留风险操作边界，不把仲裁、订单和资金判断写成前端假逻辑

### 管理端

- 管理首页统计与风险治理中枢
- 用户管理、角色管理、任务监控、资金监控
- 订单管理、争议处理和后台只读/操作入口
- 管理端视觉已收口为暖金夜色后台风格，同时保留原有权限判断和危险操作边界

### 产品展示页

`/design-showcase` 是 PC 端高保真产品全景展示页，用于集中展示浩煜的完整产品能力。它只使用 mock 数据，不调用真实接口，不影响真实业务状态。

| `/admin` | 后台管理首页 |
| `/user` | 用户管理、任务监控与资金监控 |
| `/design-showcase` | 高保真产品展示页 |

## 技术架构

```text
Frontend: Vue 3 + Vite + TypeScript + Element Plus + Vant
    |
    | REST API
    v
Backend: NestJS + Prisma + JWT/RBAC + Swagger
    |
    v
Database: Prisma-managed relational data model
```

### 前端

- Vue 3 Composition API
- Vue Router 路由与权限守卫
- Element Plus 用于 PC 端组件
- Vant 保留部分移动端结构
- Axios API 层封装
- 暖金夜色主题覆盖真实业务页与后台页

### 后端

- NestJS 模块化架构
- JWT 登录态与角色权限控制
- Prisma ORM 与迁移管理
- Task / Order / Wallet / Notification / Dispute / Admin 等业务模块
- Swagger 文档能力
- CORS、限流、上传校验和统一异常处理

## 权限模型

| 角色 | 能力边界 |
| --- | --- |
| Guest | 浏览公开页面、任务大厅和展示页 |
| User | 发布需求、接单协作、查看钱包、处理个人任务和订单 |
| Admin | 管理后台、任务/订单/争议治理入口 |
| Super Admin | 平台最高管理权限与用户治理入口 |

前端会根据路由和角色控制入口展示，后端继续负责真实权限校验。

## 状态闭环

### 任务状态

```text
PENDING -> ASSIGNED / IN_PROGRESS -> SUBMITTED -> COMPLETED
```

任务可根据业务规则进入取消、争议等状态，真实状态变更由后端接口和权限校验控制。

### 订单状态

```text
ASSIGNED -> IN_PROGRESS -> SUBMITTED -> COMPLETED
```

订单相关的开始服务、提交成果、验收、驳回、争议和后台处理都保留后端约束，不依赖前端伪造状态。

## 设计语言

浩煜 PC 端当前视觉基准为：

- 深蓝黑夜色背景
- 暖金城市灯火
- 深色玻璃卡片
- 暖金细边框与柔和内发光
- 克制状态色：暖金、蓝灰、琥珀、青绿、红铜、紫金
- 按钮与输入控件统一为暖金主按钮和深色玻璃次按钮

真实业务页面会逐步以 `/design-showcase` 为基准继续精修，但展示页本身不承载真实业务逻辑。

## 安全边界

本仓库不应包含：

- 生产密钥、服务器密码、SSH 凭据或加密 key
- `.env` 明文配置
- 数据库文件
- 用户上传文件
- 构建产物 `dist/`
- 本地截图、验收产物、日志和临时备份

涉及云端部署、服务器检查和生产操作的任务，应通过独立的安全执行流程处理，不把敏感信息写入 README 或源码。
