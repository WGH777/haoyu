# 浩煜 Haoyu — 搜索框 UI 调研报告

> 日期：2026-05-17  
> 问题：搜索框存在"白色外壳 + 深色内芯"割裂感，颜色不协调  
> 方法：调研 GitHub / Linear / Notion / Vercel / Stripe 五大平台的暗色搜索框设计

---

## 一、五大平台暗色搜索框对比

### 1.1 GitHub 暗色模式
- 页面背景: `#0d1117`
- 搜索框背景: `#0d1117`（与页面完全相同）
- 边框: `1px solid #30363d`（深灰，低对比）
- Focus: 边框变蓝 `#58a6ff` + 外发光 `0 0 0 3px rgba(88,166,255,0.3)`
- **核心思路：输入框嵌入页面，不是叠加在页面上**

### 1.2 Linear.app 暗色模式
- 页面背景: `#1a1a1a`
- 输入框背景: `rgba(255,255,255,0.02)`（极微提亮）
- 边框: `1px solid rgba(255,255,255,0.06)`（几乎不可见）
- Focus: 边框升至 `rgba(255,255,255,0.12)` + 品牌色微光
- **核心思路：输入框沉入页面，hover 才浮现**

### 1.3 Notion 暗色模式
- 页面背景: `#191919`
- 输入框背景: `rgba(255,255,255,0.055)`（微弱提亮）
- 边框: 无边框，仅靠背景微差区分
- Focus: 极微阴影
- **核心思路：零边框，靠颜色层级区分**

### 1.4 Vercel 暗色模式
- 页面背景: `#000`
- 输入框: `border: 1px solid #333`
- Focus: `border-color: #fff`（白色高亮边框）
- **核心思路：极简，focus 才宣告存在**

### 1.5 Stripe Dashboard 暗色
- 输入框背景: 略高于页面底色
- 边框: `1px solid rgba(255,255,255,0.08)`
- Focus: 品牌蓝紫光晕
- **核心思路：金融级克制，边框几乎不存在**

---

## 二、共同规律

| 属性 | 数值范围 | 说明 |
|------|---------|------|
| 边框（静止） | `rgba(255,255,255,0.06-0.10)` | 接近不可见 |
| 边框（hover） | `rgba(255,255,255,0.12-0.18)` | 微微浮现 |
| 边框（focus） | 品牌色 + 光晕 | 明确但柔和 |
| 背景 | 与页面底色差 1-3% | 嵌入感 |
| 高度 | `40-48px` | 舒适的点击区 |

**关键洞察：**

> 五个平台没有一家在输入框上使用明显的白色/亮色边框。  
> 所有平台都让输入框"沉入"页面，而非"浮于"页面上。  
> 边框在静止状态几乎不可见，hover 时微亮，focus 时才有明确反馈。

---

## 三、浩煜当前问题诊断

当前 `.search-input .el-input__wrapper` 样式：

```css
background: rgba(255, 255, 255, 0.06);    /* 偏亮，白色叠加 */
border: 1px solid rgba(148, 163, 184, 0.18); /* 边框 18% 不透明度 — 太明显 */
```

- 白色叠加背景 `0.06` 在 `#0a0e17` 上形成 `~#151a22`，与页面底色 `#0a0e17` 对比明显
- 边框 `rgba(148,163,184,0.18)` 在极暗背景上形成一道"灰白环"
- 两者叠加 → 用户看到的"白色外壳 + 深色内芯"

---

## 四、推荐方案：GitHub + Linear 融合风格

最适合浩煜"可信协作中枢"气质的方向：

| 属性 | 静止 | hover | focus |
|------|------|-------|-------|
| 背景 | 与页面同色 `#0a0e17` | 微亮 | 微亮 |
| 边框 | `rgba(255,255,255,0.06)` 极隐 | `rgba(255,255,255,0.14)` | `rgba(99,102,241,0.45)` |
| 光晕 | 无 | 无 | `0 0 0 3px rgba(99,102,241,0.12)` |

**设计理由：**
- 搜索框是高频使用的功能型组件，不需要"抢眼"
- 静止时融入背景，需要时 hover 微浮，输入时 focus 明确
- indigo 品牌色光晕与浩煜整体设计系统一致
- 避免白色外壳 — 边框只在需要时才出现

---

## 五、结论

选 **GitHub 嵌入风格 + Linear 微动效** 融合方案：

```
静止：嵌入页面，边框极隐（rgba 255/255/255 0.06）
hover：微浮提示（边框升至 0.14）
focus：品牌光晕响应（indigo 边框 + 3px 光环）
```

这比当前方案的 `0.18` 不透明度边框 + `0.06` 白色背景叠加低调约 60%，且更符合顶级 SaaS 产品的设计语言。
