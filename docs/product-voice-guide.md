# 浩煜 Haoyu — 产品语气规范

> 版本：V1.0  
> 原则：先让用户理解，再让用户感到轻松。资金/安全场景永远正式。

---

## 三档语气体系

### 🅰️ A 档 — 正式严谨

**适用场景：** 资金、结算、退款、仲裁、安全、协议、封禁

**规则：**
- 不使用玩笑、梗、口语化表达
- 信息完整，责任边界清晰
- 确认操作前必须二次确认

**示例：**
| 场景 | 旧文案 | 新文案 |
|------|--------|--------|
| 资金冻结 | 钱已冻住 | 资金已进入托管，服务完成后自动结算 |
| 退款成功 | 退款成功 | 资金已退回你的钱包，可在钱包中心查看 |
| 争议提示 | 有争议 | 该订单存在争议，资金已冻结等待处理 |
| 结算提示 | 结算完成 | 订单结算完成，收入已到账 |

---

### 🅱️ B 档 — 专业自然

**适用场景：** 发布、编辑、保存、浏览、搜索、通知

**规则：**
- 像真人协助用户
- 简洁清晰，不过度修饰
- 可以亲切但不能油腻

**示例：**
| 场景 | 旧文案 | 新文案 |
|------|--------|--------|
| 发布需求 | 请输入标题 | 起个清楚的名字，让人一眼知道你需要什么 |
| 描述 | 请输入描述 | 说说背景、目标和期望的结果 |
| 赏金 | 赏金 | 你愿意为这个需求支付多少？ |
| 保存 | 保存 | 保存 |
| 发布按钮 | 提交 | 发布需求 |
| 搜索 | 搜索任务 | 搜索你需要的服务 |
| 登录 | 登录 | 登录浩煜 |
| 注册 | 注册 | 加入浩煜 |

---

### 🅲️ C 档 — 轻微温度

**适用场景：** 空状态、成功提示、加载中、404、新手引导

**规则：**
- 可以有轻微幽默
- 不使用低俗梗、攻击性文案、阴阳怪气、短期热梗
- 始终给出下一步操作

**示例：**
| 场景 | 旧文案 | 新文案 |
|------|--------|--------|
| 空任务列表 | 暂无任务 | 这里暂时安静，新的需求可能正在路上 ✨ |
| 空通知 | 暂无通知 | 没有新通知，一切安好 |
| 空订单 | 还没有接过订单 | 去任务大厅逛逛，找到适合你的需求 |
| 发布成功 | 发布成功 | 需求已发布，等待合适的人来接单 |
| 接单成功 | — | 已接单，开始服务前先和对方打个招呼吧 |
| 404 | 页面不存在 | 你要找的页面走丢了，回任务大厅看看？ |
| 加载中 | 加载中 | 正在加载... |

---

## 核心红线

1. **资金类文案必须正式** — 不能开玩笑
2. **错误提示给原因+建议** — 不只说「失败」
3. **不使用低俗梗、攻击文案** — 用户不是朋友
4. **不给用户压力感** — 「必须」「否则」少用
5. **始终给下一步** — 每个状态都有操作出口
