# 浩煜 Haoyu — 多场景网页 UI 方向方案

> 版本：V1.0  
> 日期：2026-05-17  
> 灵感来源：Pinterest / Dribbble 设计趋势 + 国内优秀 SaaS 产品  
> 原则：不照搬任何作品，基于浩煜的「可信协作」内核进行原创适配

---

## 设计哲学

```
正规底层 + 轻松表达 + 柔和科技感

不太银行 —— 不用太严肃
不太娱乐 —— 不用太花哨
不太极客 —— 不用太小众

刚刚好的可信温度
```

## 一、可信协作中枢 UI

### 适用页面
- 登录页（/login）
- 注册页（/register）
- 信任中心（/trust）
- 后台管理（/admin/**）

### 视觉关键词
`深色科技` `蓝紫渐变光晕` `半透明玻璃卡片` `柔和输入框` `微光边框`

### 页面结构
```
┌─────────────────────────────────────┐
│          深色径向渐变背景              │
│  ┌───────────────────────────┐      │
│  │    毛玻璃登录卡片 (居中)     │      │
│  │  ┌─────────────────────┐  │      │
│  │  │  Logo + 标题         │  │      │
│  │  │  柔和输入框 (邮箱)    │  │      │
│  │  │  柔和输入框 (密码)    │  │      │
│  │  │  [登录按钮]           │  │      │
│  │  │  注册 / 游客入口       │  │      │
│  │  └─────────────────────┘  │      │
│  └───────────────────────────┘      │
└─────────────────────────────────────┘
```

### 组件风格
- **背景：** 深色 (#0a0e17) + 径向蓝紫渐变光晕
- **卡片：** 半透明毛玻璃 (backdrop-filter: blur) + 1px 微光描边
- **输入框：** 深灰底 (rgba 15,23,42, 0.85) + 低对比度边框 + focus 时 indigo 微光
- **按钮：** indigo → violet 渐变 + 柔和阴影
- **字体：** text-primary #f1f5f9（关键输入时高亮白）

### 文案语气
- 登录引导：A 档（正式）— 资金系统入口需可信感
- 注册邀请：B 档（专业自然）— 欢迎加入
- 错误提示：B 档 — 给原因 + 建议

### 禁止事项
- ❌ 亮白输入框配深色背景
- ❌ 大面积实色块
- ❌ 用户操作类机械文案
- ❌ 过度发光/霓虹

## 二、线下服务站 UI

### 适用页面
- 店员协助面板（未来 /store/**）
- 线下签到 / 任务大屏（未来 /screen/**）

### 视觉关键词
`明亮友好` `大字号` `触控友好` `高可读性` `暖色点缀`

### 页面结构
```
┌──────────────────────────────────────────┐
│  [浩煜服务站]          店员: 张姐  [退出]   │
├──────────────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐  ┌─────────┐ │
│  │ 发布需求  │  │ 查询任务  │  │ 验收确认 │ │
│  │  📝      │  │  🔍      │  │  ✅     │ │
│  └──────────┘  └──────────┘  └─────────┘ │
│  ┌──────────────────────────────────────┐ │
│  │     实时任务大厅 (大屏展示)           │ │
│  │  [热门需求] [完成榜] [信用榜]         │ │
│  └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

### 组件风格
- **背景：** 浅灰白底 (#f8fafc)
- **卡片：** 白色圆角 + 柔和阴影
- **按钮：** 大尺寸 (min 48px) 触控友好
- **字体：** 16px+ 基础字号，高对比度
- **色温：** 暖色调点缀，降低科技冰冷感

### 文案语气
- C 档（轻微温度）— 店员口吻引导
- 操作按钮用动词开头：查一下 / 帮他发布 / 确认完成

### 禁止事项
- ❌ 小字号（线下用户可能视力不佳）
- ❌ 密集信息布局
- ❌ 冷色单调

## 三、轻量金融科技 UI

### 适用页面
- 钱包中心（/wallet）
- 结算详情（未来 /settlement/**）
- 订单管理（/my-orders）

### 视觉关键词
`金融可信` `数据清晰` `简约但不冰冷` `微渐变` `等宽数字`

### 页面结构
```
┌──────────────────────────────────────────┐
│  钱包中心                                 │
├──────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐      │
│  │ 可用余额      │  │ 冻结金额      │      │
│  │ ¥1,280.50   │  │ ¥320.00      │      │
│  │ (大号等宽)   │  │              │      │
│  └──────────────┘  └──────────────┘      │
│  ┌──────────────────────────────────────┐ │
│  │  交易明细                              │ │
│  │  [日期] [类型] [金额] [状态] [操作]    │ │
│  └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

### 组件风格
- **数字：** 等宽字体 (SF Mono / Fira Code) + 大号展示
- **金额卡片：** 半透明底 + 微渐变边框
- **表格：** 清晰行高 + hover 微亮
- **状态标识：** 圆点 + 文字，色系统一

### 文案语气
- A 档（正式严谨）— 涉及资金无小事
- 确认弹窗二次确认
- 金额精确到分

### 禁止事项
- ❌ 资金类使用玩笑或口语
- ❌ 金额信息模糊（必须精确）
- ❌ 无确认直接操作

## 四、温柔移动端 UI

### 适用页面
- 所有移动端视图（响应式）
- 底部导航栏
- 触控表单

### 视觉关键词
`触控友好` `大点击区` `呼吸感` `底部导航` `卡片流`

### 页面结构
```
┌──────────────────┐
│  [顶栏: 标题/返回] │
├──────────────────┤
│                  │
│  [卡片列表流]     │
│  ┌──────────────┐│
│  │ 任务卡片 1    ││
│  ├──────────────┤│
│  │ 任务卡片 2    ││
│  └──────────────┘│
│                  │
├──────────────────┤
│ [大厅][订单][+][通知][钱包] │
└──────────────────┘
```

### 组件风格
- **底部导航：** 毛玻璃背景 + 高亮当前项
- **发布按钮：** 悬浮圆形，渐变发光
- **卡片：** 全宽圆角 + 足够间距
- **触控目标：** min 44px 高度
- **表单：** 独立聚焦，不挤占

### 文案语气
- B 档（专业自然）— 移动端简洁优先
- 缩短文案但保留温度
- 空状态用 C 档

### 禁止事项
- ❌ 过小点击区
- ❌ 横向滚动
- ❌ 桌面端组件硬塞移动端

## 五、人性化协作市场 UI

### 适用页面
- 任务大厅（/task）
- 任务详情（/task/:id）
- 我的任务（/my-task）
- 发布需求弹窗（创建任务）

### 视觉关键词
`高级任务卡片` `状态流转可视化` `榜单侧栏` `柔光筛选` `微交互`

### 页面结构
```
┌───────────────────────────────────────────────┐
│  Hero: 浩煜 · 可信价值协作平台                    │
│  [数据看板: 任务数 | 费率 | 保障 | 智能]         │
├───────────────────────────────────────────────┤
│  价值流转图: 发布→托管→执行→验收→结算→信用      │
├───────────────────────────────────────────────┤
│  [搜索] [筛选] [刷新]                            │
├─────────────────────────────┬─────────────────┤
│  任务卡片网格 (主区域)        │  榜单侧栏         │
│  ┌─────────┐ ┌─────────┐   │  热门需求         │
│  │ 卡片 1   │ │ 卡片 2   │   │  完成榜           │
│  ├─────────┤ ├─────────┤   │  信用榜           │
│  │ 卡片 3   │ │ 卡片 4   │   │  最新加入        │
│  └─────────┘ └─────────┘   │                  │
├─────────────────────────────┴─────────────────┤
│  信任机制: 资金托管 | 过程留痕 | 信用沉淀 | ...    │
└───────────────────────────────────────────────┘
```

### 组件风格
- **任务卡片：** 玻璃拟态底 + 顶部发光状态条 + hover 上浮
- **状态流转：** 可视进度条 / 步骤指示
- **榜单侧栏：** 右侧固定，毛玻璃面板
- **搜索框：** 大圆角柔和输入
- **筛选器：** 下拉自然融入

### 文案语气
- 发布/浏览：B 档（专业自然）
- 卡片简述：B 档
- 空状态：C 档（轻微温度）

### 禁止事项
- ❌ 廉价粒子特效
- ❌ 过度 3D 效果
- ❌ 短期热梗
- ❌ 机械提示语

## 统一视觉规范

### 色彩系统
| Token | 值 | 用途 |
|-------|-----|------|
| --bg-primary | #0a0e17 | 主背景 |
| --bg-secondary | #111827 | 次级背景 |
| --bg-card | rgba(17,24,39,0.75) | 卡片底 |
| --bg-input | rgba(15,23,42,0.9) | 输入框底 |
| --brand | #6366f1 | 品牌 indigo |
| --brand-light | #818cf8 | 品牌浅色 |
| --accent | #06b6d4 | 强调 cyan |
| --text-primary | #f1f5f9 | 主文本 |
| --text-secondary | #94a3b8 | 次文本 |
| --text-muted | #64748b | 弱文本 |
| --border | rgba(148,163,184,0.14) | 默认边框 |
| --border-focus | rgba(99,102,241,0.5) | 聚焦边框 |

### 输入框规范（重点）
```
背景: rgba(15, 23, 42, 0.9)
文字: #f1f5f9 (输入时高亮白)
placeholder: rgba(148, 163, 184, 0.45)
边框: rgba(148, 163, 184, 0.14)
hover 边框: rgba(148, 163, 184, 0.25)
focus 边框: rgba(99, 102, 241, 0.5)
focus 光晕: 0 0 0 3px rgba(99, 102, 241, 0.1)
圆角: 12px
字号: 14px
```

### 动效规范
- hover 上浮: 2px, 0.3s ease
- 按钮 glow: 0 → 0.3 opacity, 0.4s
- 页面过渡: 0.2s fade
- 禁止: 弹跳、旋转、闪烁、粒子

### 图标规范
- 全部使用 Element Plus 线性图标
- 避免混用实心/线条/自定义
- 导航: List / Files / Connection / Bell / Wallet
- 状态: Check / Clock / Warning / Close
- 操作: Plus / Edit / Search / Download

## 是否影响现有 API

## 是否影响路由
