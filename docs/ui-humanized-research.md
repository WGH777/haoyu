# 浩煜 Haoyu — 人性化 UI 调研报告

> 日期：2026-05-17  
> 目标：提炼适合浩煜的正规·柔和·可信·现代 UI 方向

---

## 一、现代 SaaS 平台的高级感来源

### 1.1 清晰价值主张
- 用户到达页面 3 秒内应理解平台做什么
- 浩煜当前 Hero 已做到「可信价值协作平台」
- 建议增强：一句话说清「谁帮谁，怎么帮，凭什么可信」

### 1.2 统一设计系统
- 颜色：深色底 + 半透明面板 + 柔和边框
- 圆角：12-16px 统一，让界面更「柔软」
- 间距：20-24px 网格，留白充足
- 阴影：柔和扩散，不用硬黑阴影

### 1.3 克制的动效
- hover 上浮 2px，不夸张
- 按钮 focus 用柔和光晕，不硬蓝边框
- 页面切换自然渐变过渡
- 避免弹跳、旋转、闪烁

### 1.4 柔和输入控件
- 输入框背景用半透明深色（rgba 0.04-0.06）
- 边框用低对比度（rgba 148,163,184, 0.16）
- focus 状态：淡色光晕而非硬蓝边框
- placeholder 颜色降低饱和度

### 1.5 微交互
- 卡片 hover 微浮
- 按钮 hover 柔和亮起
- 表单验证实时反馈
- 列表项 hover 高亮

### 1.6 人性化空状态
- 不说「暂无数据」，说「这里暂时安静」
- 配轻量图标/插图
- 给明确的操作指引按钮

## 二、需要避免的问题

| 问题 | 表现 | 浩煜是否踩 |
|------|------|:---:|
| 默认模板感 | 标准 UI 库默认样式 | ✅ 已通过设计系统覆盖 |
| 大面积硬色块 | 强对比块状背景 | ✅ 已用半透明+模糊 |
| 输入框割裂 | 亮白输入框配深色背景 | ❌ 存在 — 需优化 |
| 过度霓虹 | 刺眼发光效果 | ❌ 渐变色已克制 |
| 机械提示语 | 「请输入内容」 | ❌ 存在 — 需优化 |
| 图标风格混乱 | 不同来源/粗细的图标混用 | ❌ Element Plus 默认即可 |
| 过期热梗 | 网络流行语做 UI 文案 | ✅ 未使用 |

## 三、浩煜适配方向

### 核心定位：**正规底层 + 轻松表达 + 柔和科技感**

```
不太银行 → 不用太严肃
不太娱乐 → 不用太花哨
不太极客 → 不用太小众
刚刚好的可信温度
```

### 视觉层
- 深色科技底 + 半透明毛玻璃面板
- 柔和渐变点缀（indigo → cyan）
- 卡片微浮 hover
- 输入框融入背景

### 文案层
- 资金/结算/仲裁 → 正式严谨（A 档）
- 发布/编辑/浏览 → 专业自然（B 档）
- 空状态/成功/404 → 轻微温度（C 档）

### 图标层
- 统一 Element Plus 线性图标
- 避免实心/营销感重的图标
- 导航用 ClipboardList / Handshake / ShieldCheck 等

## 四、对比竞品

| 平台 | 借鉴 | 避免 |
|------|------|------|
| **Notion** | 柔和输入、统一设计语言 | 太轻量，缺正式感 |
| **Linear** | 深色主题、微动效 | 太极客 |
| **Stripe** | 金融科技质感 | 太冷 |
| **Framer** | 动效克制 | 太花 |
| **飞书** | 中文 SaaS 标杆 | 太企业 |

---

> 结论：浩煜应走「轻量金融科技 + 人性化 SaaS」路线。
