## 2. 拆分组件说明

### 2.1 CreateTaskDialog.vue

| 项目 | 说明 |
|------|------|
| 路径 | `components/home/CreateTaskDialog.vue` |
| 接口 | `v-model` → `showCreateDialog` + `@published` → 刷新任务列表 |
| 保留逻辑 | 发布表单、图片上传、分类选择、服务方式 |
| 移除依赖 | 不再依赖 HomeView 中的 `createForm` / `submitting` / `handleImageChange` / `submitTask` |
| CSS 迁移 | `publish-dialog-title`, `upload-btn`, `reference-preview`, `:deep(.publish-dialog)` 等全部随组件迁移 |

调用方式：

```html
<CreateTaskDialog v-model="showCreateDialog" @published="fetchData" />
```

### 2.2 MobileBottomTabs.vue

| 项目 | 说明 |
|------|------|
| 路径 | `components/home/MobileBottomTabs.vue` |
| 接口 | `:is-login` + `@publish` → 点击中央按钮时触发 |
| 保留功能 | 5 个 Tab（首页、任务、发布、保障、我的），路由跳转完整 |
| CSS 迁移 | `mobile-bottom-tabs`, `mobile-tab-item`, `tab-icon`, `mobile-tab-publish`, `gold-pulse` 动画 |

调用方式：

```html
<MobileBottomTabs :is-login="isLogin" @publish="openCreateDialog" />
```

### 2.3 MobileDrawerMenu.vue

| 项目 | 说明 |
|------|------|
| 路径 | `components/home/MobileDrawerMenu.vue` |
| 接口 | `:open` + `:is-login` + `:user` + `:title` + `:items` + `@update:open` |
| 保留功能 | 移动端 topbar、汉堡菜单、drawer、用户 ActionSheet、退出/登入 |
| CSS 迁移 | `mobile-topbar`, `mobile-drawer`, `mobile-drawer-menu`, `mobile-drawer-footer` 等全部随组件 |

调用方式：

```html
<MobileDrawerMenu
  :open="mobileDrawerOpen"
  :is-login="isLogin"
  :user="currentUser"
  :title="mobileTitle"
  :items="mobileMenuItems"
  @update:open="mobileDrawerOpen = $event"
/>
```
