### 3.2 effects.scss（+181 行）

**新增通用工具类**:

| 类名 | 用途 |
|------|------|
| `hy-card` | 标准卡片底座（玻璃拟态 + 微光边框 + 阴影） |
| `hy-glass-card` | 高透玻璃卡片（更低不透明度） |
| `hy-card-hover` | 带悬浮效果的卡片（hover 微升 + 发光） |
| `hy-card-layer-1/2/3` | 卡片层级阴影选择器 |
| `hy-section-title` | 区块标题（如"热门需求""完成榜"） |
| `hy-gold-text` | 暖金色渐变文字（价格/高亮） |
| `hy-mobile-safe-bottom` | 移动端底部安全间距 |
| `hy-glow-border` | 顶部发光微光条（卡片 hover） |
| `hy-city-skyline-divider` | 城市天际线渐变分隔线 |

**新增动画**:

| Keyframes | 用途 |

| `light-twinkle-soft` | 柔和版闪烁 |

## 7. Phase 1 后续建议

根据设计文档 `v0.2.6-frontend-visual-upgrade-plan.md`，建议 Phase 1 按以下顺序实施：

### 优先级 P0（高价值、低风险）

1. **HomeView.vue → HeroSection 样式替换**
   - 将 Hero 区现用内联光点 CSS 改为引用 `light-twinkle` 动画
   - 使用 `hy-gold-text` 替换标题渐变
   - 使用 `hy-card` 替换数据看板卡片样式
   - 预计影响: HomeView.vue 约 50 行样式

### 优先级 P1（中等价值）

2. **任务卡片引用 `hy-card-hover` 替换现有 `.task-card-premium` 核心样式**
   - `.task-card-premium` 已有大部分属性，可以引用 `hy-card` 底座
   - 预计影响: effects.scss 中 `.task-card-premium` 精简

3. **榜单侧栏替换为 `hy-section-title` + `hy-card-layer`**
   - `leaderboard-panel` 中的 title 和 shadow 可以对齐 token
   - 预计影响: effects.scss 中 `.leaderboard-panel` 精简

### 优先级 P2（低风险、渐进式）

4. **暖金按钮的渐进引入**
   - 在 CTA 区域（发布需求、注册）逐步替换 `type="warning"`

5. **移动端安全间距 `hy-mobile-safe-bottom` 引用**
   - 任务列表容器添加该类，替代硬编码 `padding-bottom`

### 禁止在 Phase 1 做的事

- ❌ 拆分 HomeView.vue 为多个组件（Phase 2 再做）
- ❌ 修改 API 或后端代码
- ❌ 引入新 UI 库
- ❌ 大规模重构布局
