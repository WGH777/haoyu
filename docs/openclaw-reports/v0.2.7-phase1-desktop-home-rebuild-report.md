## 5. PC 首页结构变化

### 旧结构（v0.2.6-hotfix-2）
```
sidebar → topbar → hero-v2 → dashboard → value-flow → filter → task-grid → leaderboard → trust → footer
```

### 新结构（v0.2.7 Phase 1）
```
HomeTopNav（横向导航）
└── HomeHero（城市灯火 + 灯笼SVG + 标题 + 暖金CTA）
└── HomeStatsStrip（服务用户/完成订单/好评率/托管资金）
└── HomeValueFlow（五步流程卡片）
└── ServiceCategoryGrid（8分类图标宫格）
└── FeaturedTaskSection（精选任务三列图文卡片）
    └── FeaturedTaskCard（封面SVG + 标签 + 价格 + 时间）
└── [保留旧 dashboard + filter + task-grid + trust + footer]
```

### 任务卡片图文化

| 分类 | 默認封面 SVG | 触发条件 |
|------|:-----------:|----------|
| 设计创作 | `task-cover-design.svg` | category=DESIGN 或 SKILL_SERVICE 设计类 |
| 技术开发 | `task-cover-dev.svg` | category=SKILL_SERVICE |
| 视频制作 | `task-cover-video.svg` | category=VIDEO |
| 营销推广 | `task-cover-marketing.svg` | category=MARKETING |
| 文案策划 | `task-cover-writing.svg` | category=WRITING |
| 数据标注 | `task-cover-data.svg` | category=DATA |
| 其他 | `task-cover-design.svg` | fallback |

如果任务已有 `image` 或 `referenceImage` 字段，优先使用真实上传图。
