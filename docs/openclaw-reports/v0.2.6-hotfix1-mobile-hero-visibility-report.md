## 2. 手机端视觉增强摘要

### 2.1 暖金黄色额外光点

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 光点数量 (PC) | 24 个 | 24 个 ✅ (未变) |
| 光点数量 (手机端) | 24 个 | **24 + 8 = 32 个** |
| 额外光点位置 | 无 | 正弦/余弦分布式 |
| 额外光点颜色 | 无 | 暖金 `rgba(251,191,36,0.9)` |
| 额外光点大小 | 无 | 4px, 6px, 8px 三档 |
| PC 端影响 | — | ❌ 无 (`mobile-extra-dot { display:none }`) |

**效果**: 手机 Hero 区增加 8 个暖金色光点均匀分布，与原有的 24 个光点叠加，营造"万家灯火"氛围。

### 2.2 手机端 slogan 字体增强

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 字体大小 | `16px` | **`20px`** |
| 文字微光 | 无 | `text-shadow: 0 0 20px rgba(251,191,36,0.08)` |

**效果**: "让需求有着落，让协作有回响" 在手机上更醒目，微光增加文字质感。

### 2.3 CTA 暖金按钮呼吸动画

**效果**: "✨发布需求" 按钮在手机端有轻微的暖金呼吸节奏，吸引点击。
