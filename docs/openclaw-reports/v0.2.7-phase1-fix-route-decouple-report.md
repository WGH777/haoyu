## 2. 路由调整说明

### 调整前（失败的 cd691e2）

```typescript
{ path: '/', component: HomeView, children: [
    { path: '/task', component: HomeView, ... },
    { path: '/task/:id', ... }, ...
]}
```

**问题**: `/` 和 `/task` 都渲染同一个 `HomeView.vue`，新 Landing 组件和旧组件混在同一个 template 内。

### 调整后

```typescript
{ path: '/',      name: 'home', component: LandingHomeView, meta: { public: true } },

{ path: '',       component: HomeView, children: [
    { path: '/task',    component: HomeView, ... },
    { path: '/task/:id', ... },
    { path: '/my-task', ... },
    // ...
]},
```

**关键变化**:

| 路由 | 渲染的组件 | 包含内容 |
|------|-----------|----------|
| `/` | `LandingHomeView` | 新首页：HomeTopNav + HomeHero + Stats + Flow + CategoryGrid + FeaturedTask |
| `/task` | `HomeView` (children) | 旧任务大厅：sidebar + topbar + filter + task-grid + trust + footer |
| `/task/:id` | `TaskDetail` | 不变 |
| `/login` / `/register` | `LoginView` / `Register` | 不变 |

**HomeView.vue** 已通过 `git checkout 72b4d55 -- apps/frontend/src/views/HomeView.vue` 精确恢复到 hotfix-2 稳定版本（2042 行），保持了 sidebar、topbar、Hero、dashboard、value-flow、task-grid、leaderboard、trust、footer 等完整结构。

### 路由合并问题说明

由于 `/` 不再是 `HomeView` 的 children，而 `/task`（含其 children `/task/:id`、`/my-task` 等）仍保留在 `HomeView` 的 children 中，两者**完全独立渲染**，不再互相干扰。

## 4. LandingHomeView.vue 结构

```text
LandingHomeView.vue (~155 行)
├── HomeTopNav（props: isLogin / user / walletBalance / searchKeyword）
├── HomeHero（@publish → handlePublish）
├── HomeStatsStrip（stats: 5万/2万/98%/500万）

└── MobileDrawerMenu（:open / :items / @update:open）
```

### LandingHomeView 的数据来源

| 数据 | 来源 | 说明 |
|------|------|------|
| `isLogin` | `computed(() => !!localStorage.getItem('token'))` | 与 HomeView 一致 |
| `currentUser` | `getProfile()` API + localStorage | 与 HomeView 一致 |
| `walletBalance` | `getWallet()` API | 与 HomeView 一致 |
| `tasks` | `getTaskList()` API | 前 6 条用于精选卡片 |
| `showCreateDialog` | ref | 打开/关闭发布弹窗 |
| `mobileDrawerOpen` | ref | 移动端菜单 |

**注意**: LandingHomeView 不依赖 `HomeView` 的任何状态，完全独立。
