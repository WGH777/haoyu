### 4.3 Nginx limit_req 配置确认

```nginx
# nginx.conf
map $http_cf_connecting_ip $login_limit_key {
    ""      $binary_remote_addr;
    default $http_cf_connecting_ip;
}
limit_req_zone $login_limit_key zone=login_limit:10m rate=30r/m;

# haoyu-admin.conf (admin.haoyulv.com)
location /api/auth/login {
    limit_req zone=login_limit burst=5 nodelay;
    limit_req_status 429;
    error_page 429 @login_429;
    proxy_pass http://127.0.0.1:3000/api/auth/login;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $login_limit_key;
    ...
}
```

✅ 配置完整：Cloudflare CF-Connecting-IP 正确映射为限流键 + proxy X-Real-IP。

## 5. Backend 接收 body 检查

### 5.1 后端登录处理流程

```
POST /api/auth/login → LoginThrottleGuard → AuthController.signIn()
```

### 5.2 验证结果

后端错误日志中出现的 `400 BadRequest "email should not be empty"` 共 3 次，全部来自**客户端未发送 email 字段**，而非 Nginx 丢失 body：

```
[HttpExceptionFilter] {
  status: 400,
  error: 'BadRequestException',
  message: 'email should not be empty; email must be an email',
  path: '/api/auth/login',
  method: 'POST'
}
```

这些是 **客户端问题**（旧前端、测试脚本、爬虫等），不是 Nginx 代理层问题。

### 5.3 Body 解析验证

在 `AuthController.signIn()` 中：

```typescript
async signIn(@Req() req: any, @Body() dto: LoginDto) {
    if (!dto || !dto.email || !dto.password) {
      throw new BadRequestException('email/password required');
    }
    ...
}
```

✅ 如果 body 丢失，会抛出 `BadRequestException('email/password required')`。但从我们的 curl 测试来看，正确返回的是 `401 账号或密码错误`，说明 body 已被成功解析为 dto.email 和 dto.password。

**透传正常**，无 IP 错误传递。
