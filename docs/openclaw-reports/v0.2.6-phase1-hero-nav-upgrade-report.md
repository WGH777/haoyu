## 2. Hero 视觉改动摘要

### 2.1 标签行升级

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 图标 | 🔒（锁） | 🏮（灯笼） |
| 文字 | 资金托管 · 信用沉淀 · 智能仲裁 | **万家灯火** · 资金托管 · 信用沉淀 |

品牌关键词"万家灯火"加入标签行，体现 C 方向烟火温度。

### 2.2 主副标题重构

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 主标题 | 浩煜 Haoyu | ✅ 不变 |
| 副标题（主要） | 可信价值协作平台 — 连接真实需求，激活真实能力，保障可信交付 | **让需求有着落，让协作有回响** |
| 副标题（次要） | (无) | **可信价值协作平台**（新增，更小字号灰字） |

- 主 slogan "让需求有着落，让协作有回响" 成为 Hero 核心文案（18px 粗体）
- 原 slogan "可信价值协作平台" 降级为次要副标题（14px 淡灰，保持品牌识别）
- 间距、字号、字重均调整

### 2.3 CTA 按钮暖金化

| 按钮 | 修改前 | 修改后 | 效果 |
|------|--------|--------|:----:|
| 发布需求 / 创建协作身份 | `type="primary"` 紫蓝渐变 | `type="warning"` + `btn-warm-gold` | **暖金色按钮**，`#fbbf24 → #f59e0b` 渐变 |
| 浏览任务 / 了解保障 | 轮廓按钮 | ✅ 不变 | 保持轮廓风格 |

暖金色主按钮使用 Phase 0 的 `el-button--warning` 样式基座，配合 `btn-warm-gold` 增加发光阴影和高亮。

### 2.4 Hero 底色渐变增强

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 渐变层数 | 3 层径向渐变 | **4 层**：顶部紫蓝 + 右上暖金 + 左下青 + **底部暖金** |
| 底部暖光 | 无 | `radial-gradient(ellipse at 50% 80%, rgba(251,191,36,0.04) 0%, transparent 50%)` |

### 2.5 灯光分层

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 光点动画 | `twinkle` | `light-twinkle`（引用 Phase 0 keyframes） |
| 背景光晕 | 无 | `hero-lights::after` 添加了紫蓝 + 暖金径向渐变覆盖层 |
| 动画帧 | `twinkle 3s ease-in-out infinite` | `light-twinkle 3s ease-in-out infinite` |

### 2.6 SVG 流转图

**不变**。流转节点的颜色映射（紫蓝→暖金→青→绿→紫）自然适配融合方向。

## 9. 视觉效果对比（描述）

### Phase 0 → Phase 1 首页变化：

```
Phase 0（token 底座准备好，但未使用）
 ┌─────────────────────────────┐
 │ 👋 可信价值协作平台          │  ← 顶栏纯文字
 ├─────────────────────────────┤
 │ 🔒 资金托管 · 信用沉淀      │  ← 标签锁图标
 │ 浩煜 Haoyu                  │
 │ 可信价值协作平台 — 连接…    │
 │ [紫蓝渐变] [浏览任务]       │  ← 紫蓝 CTA
 └─────────────────────────────┘

Phase 1（视觉升级完成）
 ┌─────────────────────────────┐
 │ [煜] 可信价值协作平台        │  ← 顶栏加品牌徽标
 ├─────────────────────────────┤
 │ 🏮 万家灯火 · 资金托管      │  ← 标签灯笼+万家灯火
 │ 浩煜 Haoyu                  │
 │ 让需求有着落，让协作有回响   │  ← 新 slogan（粗体加大）
 │ 可信价值协作平台            │  ← 次要副标题（淡灰小字）
 │ [暖金🌟] [浏览任务]         │  ← 暖金 CTA
 │    底部暖光渐变 ████        │  ← 底部暖光层
 └─────────────────────────────┘
```

### 关键用户感知差异：
1. **顶部**：多了品牌方块标「煜」，视觉专业化提升
2. **Hero 标题**：slogan 从描述性变为情感化（"让需求有着落，让协作有回响"）
3. **CTA 按钮**：从紫蓝变为暖金，与价格文字的金色呼应
4. **氛围**：底部暖光 + 万家灯火标签，温暖感增强
5. **移动端**：slogan 字号从 14px 提升到 16px，阅读性更好
