## 核心功能变更

### 前端 — 移动端深度打磨

- 任务卡片两列网格布局（600-768px 断点）
- 移动端 FAB 底部留空优化（`padding-bottom: 110px + env(safe-area)`）
- 卡片描述单行截断 + 角标缩小
- 任务详情页移动端按钮层级 class（primary / secondary / small）
- Vant 弹层整合（空态、tabs 筛选）
- 移动端子任务按钮风格优化

### Admin-next — 用户治理

- 操作列宽度 `160px → min-width: 220px`
- flex-wrap 按钮容器 `.user-action-buttons`
- 按钮高度统一 28px，圆角 6px，间距 6px，覆盖 Element Plus 默认 margin
- 调整角色按钮 `type: primary → warning`（描边层级统一）
- 移动端卡片不受影响，独立 CSS class

## 已知非阻塞问题

1. **`apps/admin/.env.production` 被 git 跟踪** — 内容为 Vite 公开构建变量（base path、路由模式、CDN 开关、压缩选项），无密码/token/密钥。属于历史遗留跟踪问题，建议后续版本通过 `.gitignore` 修复。
2. **遗留订单 #12 金额缺失** — 后端日志有 WARN 提示，不影响生产功能。可安排后续数据修复。
3. **`pnpm-workspace.yaml` 本地脏改** — 恢复至原始提交版本，不纳入本次发布。

## 观察期建议（发布后 7 天）

1. 访问 www.haoyulv.com 确认移动端两列卡片、FAB 正常显示
2. 访问 admin.haoyulv.com/admin/users 确认操作列 2 列按钮自动换行
3. 监控 PM2 日志（`pm2 logs haoyu-backend --lines 50`），关注 ERROR 级输出
