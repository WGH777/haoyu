## 429 JSON 配置

```nginx
# 在 /api/auth/login location 中
location /api/auth/login {
    limit_req zone=login_limit burst=5 nodelay;
    limit_req_status 429;
    error_page 429 @login_429;       # ← 新增：429 时转 JSON 响应

    proxy_pass http://127.0.0.1:3000/api/auth/login;
    ...
}

# 命名 location：返回 JSON
location @login_429 {
    default_type application/json;
    add_header Content-Type application/json;
    return 429 '{"statusCode":429,"error":"TooManyRequests","message":"Too many login attempts, please try again later","path":"/api/auth/login","timestamp":"$time_iso8601"}';
}
```

### 响应格式

```json
{
  "statusCode": 429,
  "error": "TooManyRequests",
  "message": "Too many login attempts, please try again later",
  "path": "/api/auth/login",
  "timestamp": "2026-06-05T11:51:13+00:00"
}
```

| 层 | Content-Type | Body |
