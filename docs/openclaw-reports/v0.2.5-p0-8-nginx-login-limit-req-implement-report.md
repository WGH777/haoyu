## limit_req 配置

### nginx.conf http 块

```nginx
# 登录限流：使用 Cloudflare 真实 IP（CF-Connecting-IP），空值回退到 remote_addr
map $http_cf_connecting_ip $login_limit_key {
    ""      $binary_remote_addr;
    default $http_cf_connecting_ip;
}
limit_req_zone $login_limit_key zone=login_limit:10m rate=30r/m;
```

### admin.haoyulv.com + www.haoyulv.com — conf.d/*.conf

```nginx
# 登录限流（使用 Cloudflare 真实 IP）
location /api/auth/login {
    limit_req zone=login_limit burst=5 nodelay;
    limit_req_status 429;

    proxy_pass http://127.0.0.1:3000/api/auth/login;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $login_limit_key;        # ← 使用真实 IP
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 真实 IP 头处理方式

| 变量 | 来源 | 回退策略 | 用途 |
|------|------|---------|------|
| `$login_limit_key` | `map $http_cf_connecting_ip` | `$binary_remote_addr` | Nginx 限流 key + X-Real-IP |
| `$http_cf_connecting_ip` | Cloudflare 代理头 | — | 选中的限流 key 来源（CF 代理时始终存在） |
| `$binary_remote_addr` | 直连 IP | — | 非 CF 场景的回退 |

**同步修正**: 原有 `/api/` 通用 catch-all 的 `X-Real-IP` 也改为 `$http_cf_connecting_ip`（8 位用户 IP，非 CF 节点 IP）。

### 失败场景处理

| 场景 | 处理 |
|------|------|
| `nginx -t` 语法错误 | 配置文件未写入容器（ro 挂载不生效），修正即可 |
| `nginx -s reload` 失败 | 旧配置继续运行，不影响线上 |
| Nginx 429 误伤过多 | 注释 limit_req 行 → reload，1 秒恢复 |
