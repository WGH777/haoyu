## 2. 任务卡片视觉改动摘要

### 2.1 effects.scss — 任务卡片基座升级

| 项目 | 修改前 | 修改后 | 效果 |
|------|--------|--------|:----:|
| **hover 上浮** | `translateY(-2px)` | `translateY(-3px)` | 上浮更多，质感更强 |
| **hover 阴影** | `0 8px 40px rgba(99,102,241,0.08)` | `0 10px 48px rgba(99,102,241,0.1)` | 阴影更大、更透亮 |
| **active 回弹** | `translateY(0)` | `translateY(-1px)` | 点击后不完全回弹，保留轻飘 |
| **标题字重** | `font-weight: 600` | `font-weight: 700` | 标题更突出 |
| **标题换行保护** | 无 | `display:-webkit-box; -webkit-line-clamp:2; overflow:hidden` | 两行截断，防止长标题撑破 |
| **价格颜色** | 纯色 (effects 未定义) | `linear-gradient(#fcd34d,#f59e0b)` 渐变色 | 暖金价格贯穿全站 |

### 2.2 effects.scss — 高预算卡片暖金强化（新增）

移除了原有 scoped 样式中的 `.high-budget` 处理，统一到 effects.scss 基座：

```scss
&.high-budget {
  border-color: rgba(251, 191, 36, 0.2);        // 暖金边框
  &::before {
    background: linear-gradient(90deg, transparent, rgba(251, 191, 36, 0.5), transparent);
  }
  &:hover {
    border-color: rgba(251, 191, 36, 0.35);
    box-shadow: 0 10px 48px rgba(251, 191, 36, 0.1);
  }
}
```

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 配色 | `rgba(245,158,11,0.2)` (amber) | `rgba(251,191,36,0.25)` (gold, 更亮) |
| hover 边框 | `rgba(245,158,11,0.4)` → `0 8px 40px` | `rgba(251,191,36,0.35)` → `0 10px 48px` |
| 顶部微光 | 品牌紫蓝色 | **暖金色**微光条 |

### 2.3 effects.scss — 价格全局渐变

```scss
.premium-card-price {
  background: linear-gradient(135deg, #fcd34d, #f59e0b);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
}
```

所有任务卡片的 `💰 xxx煜米` 价格文字统一为暖金渐变，替代之前散落在不同位置的 `.glow-amber` 类引用。

### 2.4 HomeView.vue — 网格与标记优化

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 网格列宽下限 | `minmax(290px, 1fr)` | `minmax(300px, 1fr)` | 
| 高预算边框色 | `rgba(245,158,11,0.2)` | `rgba(251,191,36,0.25)` (暖金统一) |
| 高预算 hover | `0 8px 40px rgba(245,158,11,0.08)` | `0 10px 48px rgba(251,191,36,0.1)` |
| 角标 hot | `rgba(245,158,11,...)` amber | `rgba(251,191,36,...)` gold (统一暖金) |
| 角标 new | `rgba(6,182,212,...)` cyan | `rgba(99,102,241,...)` brand (品牌色) |
| 价格 CSS | `<span class="premium-card-price glow-amber">` | `<span class="premium-card-price">` |
| 移动端价格 | `color: #fcd34d` 纯色 | `background: linear-gradient(...)` 渐变 |
