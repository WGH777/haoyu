## 1. 根因：HomeView.vue 不是替换，而是堆叠

### 直接原因

| # | 失败现象 | 根本原因 |
|---|---------|----------|
| 1 | 左侧旧 sidebar 出现在首页 | `cd691e2` 在保留 `<aside class="sidebar">` 的情况下，新增了 `<HomeTopNav>`，导致两个导航同时渲染 |

### 根因一句话

## 4. 推荐修复路线：新增 LandingHomeView.vue，不拆 HomeView.vue

### 核心决策

**不修改 HomeView.vue，不修改路由。**  
新增 `LandingHomeView.vue` 作为 `/` 首页专用组件，将 `HomeView.vue` 只留给 `/task`。

### 为何不拆 HomeView.vue 也够？

当前路由结构：

```typescript
{
  path: '/',
  component: HomeView,      // 主布局
  children: [
    { path: '/task', component: HomeView, ... },
    { path: '/task/:id', ... },
    { path: '/my-task', ... },
    // ...
  ]
}
```

`/` 会渲染 HomeView，`/task` 也会渲染 HomeView（作为 children）。  
所以 `HomeView.vue` 的 template 同时被 `/` 和 `/task` 共用。

**修复方案**：让 `'/'` 路由使用 `LandingHomeView.vue`，`'/task'` 继续使用 `HomeView.vue`。

### 不拆 HomeView.vue 的代价

HomeView.vue 当前仍有 1796 行，包含 sidebar、topbar、hero（旧）、dashboard、value-flow、filter、task-grid、trust、footer 等。留在 `/task` 没问题，但新首页需要完全不同的结构。

// ...

const categories = computed(() => [
