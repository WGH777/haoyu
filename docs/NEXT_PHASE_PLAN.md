## 逐级推进规则

```
阶段一（安全）→ 二（体验）→ 三（打磨）
  ↓                ↓              ↓
 不可跳过         依赖一完成     依赖二完成
```

- **每完成一项 → 测试 → commit → push → 部署**
- **每阶段完成后 → 全链路回归测试 → 给你汇报 → 确认进入下一阶段**
- **不为速度牺牲安全**：涉及资金/权限的改动必须双审
