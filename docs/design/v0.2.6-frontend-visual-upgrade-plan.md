### 1.3 当前视觉体系定位

当前设计理念为 **深色科技风格**，核心特征：

| 维度 | 当前实现 | 描述 |
|------|---------|------|
| 背景色 | `#0a0e17` 深色底 | 纯黑底偏蓝，接近午夜蓝 |
| 品牌色 | `indigo-500 (#6366f1)` | 紫蓝色为主色调 |
| 强调色 | `cyan-500 (#06b6d4)` | 青色作为强调 |
| 金色 | `amber (#f59e0b / #fcd34d)` | 用于价格、高级标签 |
| 卡片风格 | `glass-card` 玻璃拟态 | `backdrop-filter: blur` + 半透明背景 |
| 圆角 | 6px ~ 20px | 分层：sm/md/lg/xl |
| 阴影 | `0 4px 24px rgba(0,0,0,0.3)` | 卡片阴影柔和 |
| 字体 | 系统字体栈 | PingFang SC / Microsoft YaHei |
| Hero | 万家灯火主题 | 动态光点 + 颜色渐变 + SVG 流转图 |
| 按钮 | 渐变紫蓝 + 发光 | `linear-gradient(135deg, #6366f1, #8b5cf6)` |

当前视觉已初步融合了 **A 暖金夜色**（深色底、发光、金色）和 **C 烟火温度**（万家灯火主题、光点动画、琥珀色文字），但缺少 **B 极简高级** 的克制排版、留白和卡片层级感。

### 1.4 HomeView.vue 是大文件问题

HomeView.vue 是当前前端的核心文件，承载了：
- 侧边栏布局
- 顶部导航
- Hero 区（含万家灯火动画）
- 数据看板
- 价值流转图
- 搜索/筛选区
- 任务卡片网格
- 榜单侧栏
- 信任机制区
- 页脚
- 发布弹窗
- 移动端顶栏 + 抽屉菜单 + FAB
- 完整的 `<style>`（~800+ 行）

**风险**: 单文件 ~2000+ 行（含 ~800+ 行 style），属于大组件，修改不便。

## 3. 组件拆分建议

### 3.1 拆分策略

当前 HomeView.vue 是一个单体页面，包含侧边栏、顶部栏、Hero、数据看板、搜索、任务卡片网格、榜单侧栏、信任区、页脚、发布弹窗、移动端导航共约 **12 个独立功能区域**。

**拆分原则**：
1. 每个独立功能区域拆为独立组件
2. 组件之间通过 props/events 通信，不共享内部状态
3. 全局状态（登录、用户信息、钱包余额、未读数）保留在 HomeView 层或 Pinia store
4. 样式从 HomeView 的 `<style scoped>` 中移出至各自组件

### 3.2 组件树设计

```
HomeView.vue (页面容器)
├── NavSidebar.vue             # 左侧导航栏（PC）
├── TopBar.vue                 # 顶部栏 + 用户入口
├── HeroSection.vue            # Hero 区（万家灯火动画 + 流转SVG）
├── DashboardStats.vue         # 数据看板
├── ValueFlowSection.vue       # 协作流转（增强版）
├── FilterRow.vue              # 搜索 + 筛选
├── TaskCardGrid.vue           # 任务卡片网格
│   └── TaskCardPremium.vue    # 单张任务卡片
├── LeaderboardPanel.vue       # 榜单侧栏（含3面板）
├── TrustSection.vue           # 信任保障区
├── PageFooter.vue             # 页脚
├── CreateTaskDialog.vue       # 发布需求弹窗
├── MobileTopBar.vue           # 移动端顶栏
├── MobileDrawerMenu.vue       # 移动端抽屉菜单
└── MobileFab.vue              # 移动端浮动按钮
```

```

├── 直接使用: NavSidebar, TopBar, MobileTopBar, MobileDrawerMenu, MobileFab
│              (布局容器层)

│   ├── HeroSection, DashboardStats, ValueFlowSection

│   └── <router-view> (子路由组件)
├── 全局 dialog: CreateTaskDialog
└── 全局状态管理:
    ├── isLogin, currentUser, walletBalance, unreadCount
    ├── tasks[], searchKeyword, priceFilter

    └── mobileDrawerOpen, showMobileUserSheet
```

## 4. CSS 变量 / 设计 token 建议

### 4.1 融合后视觉基调

融合 A · B · C 三个方向后的统一视觉系统：

| 维度 | 描述 | 代表用户感受 |
|------|------|------------|
| 底色 | 深色科技底 + 暖金点缀 + 万家灯火意象 | 可信、温暖、专业 |
| 品牌色 | 保留 `#6366f1` 紫蓝渐变作为品牌主色 | 专业可信 |
| 暖金色 | 新增 `#fbbf24` / `#f59e0b` 作为价格/高亮/CTA 强调 | 价值感、温暖 |
| 城市灯火 | 动态光点 + 暖色烟雾动画 | 万家灯火、烟火气息 |
| 排版克制 | 增大留白、缩小正文字号、增大标题字重 | 高级感 |
| 卡片层级 | `z-index` 堆叠 + 内阴影/外阴影分层 | SaaS 质感 |

## 8. 风险点

## 9. 回滚方案

### 9.1 回滚策略

| 场景 | 回滚操作 | 影响 |
|------|---------|:----:|
| 构建失败 | `git checkout -- apps/frontend/` + 重新构建 | **无**（未部署） |
| 部署后视觉异常 | 回退前端静态文件：从备份或 git revert | **< 1 分钟** |
| 后端不兼容 | 如有 API 变更：回退后端 + 前端一起 | **2 分钟** |
| 数据库不兼容 | 本方案不涉及数据库变更，无需回滚 | **无** |

### 9.2 前端构建后回滚

```bash
# 方案 A：git revert（推荐）
git revert HEAD --no-edit
git push

# 方案 B：手动恢复 dist
# 假设 /var/www/html/haoyu 为当前部署目录
cp -r /var/www/html/haoyu /var/www/html/haoyu.backup.$(date +%Y%m%d_%H%M)
rsync -av --delete /tmp/haoyu-dist-backup/ /var/www/html/haoyu/
```

### 9.3 可回滚保障要求

1. 每次 Phase 完成、验证通过后 **创建 git commit**
2. 构建前 **备份当前 dist**（`cp -r dist dist.backup`）
3. 不合并多个 Phase 成一个 commit，保证回滚粒度在一个 Phase 内
4. 部署前确保 `npm run build` 通过
